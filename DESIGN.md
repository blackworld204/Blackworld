# Blackworld

| Decision | Choice |
| --- | --- |
| Product mode | Persuade, with short operational tasks (apply, login, convert, read the API) |
| Audience | Fintech and institutional teams evaluating a banking partner, then returning to apply or read docs |
| Visual world | Charter — a private-bank prospectus set in type, not a startup landing page |
| Palette family | Warm ink on bone paper, pine for action, one citron mark on dark bands |
| Type treatment | Instrument Serif for display, Instrument Sans for interface, IBM Plex Mono for figures and code |
| Composition | Editorial document. First screen is headline, ledger, and a stats rule. Later sections are ruled columns, not cards |
| Shape language | Hairline rules, 2px corners, no shadows |
| Anti-references | Purple gradients, glass cards, emoji flags, equal icon tiles, pill buttons, Inter |

The site carries the same jobs as a banking-as-a-service prospectus: partnership, login, API reference, a product walkthrough, currency conversion, sales, and support. The visual system stays on paper and ink so those jobs stay quiet and fast.
